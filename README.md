# LeshDevs

LeshDevs is a student-first platform for learning programming foundations and putting new skills to the test. Start with Python, Java, HTML, CSS, JavaScript, or C; earn points through challenges and climb the E–D–C–B–A–S rank ladder. Discover additional learning opportunities in the Source Wall.

## Features

- Six starter language tracks, each with a learning progress view.
- Quick challenges with instant feedback and points for correct answers.
- An S/A/B/C/D/E rank system driven by accumulated points.
- A Source Wall linking to MIT OpenCourseWare, Bro Code, and freeCodeCamp.
- Responsive dashboard; demo points persist in the current browser using local storage.

## Development

- `npm install`
- `npm run dev`
- `npm run build`

This frontend demo stores points locally in the browser. Shared accounts, synced progress, and a live multiplayer leaderboard need a backend and are not part of this app yet.
